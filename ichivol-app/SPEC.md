# Mini-spec — IchiVol App

## Objectif
App web screener + chart : signaux Ichimoku validés seulement si RVOL confirme.

## Stack (décision)
Vite + React + TypeScript + lightweight-charts + Binance public REST (proxy Vite).

## Hors-scope MVP
Courtage, actions/forex, auth, alertes push, intégration JARVIS.

## Terminé quand
`npm run build` OK ; chart Ichimoku+volume ; screener multi-paires.
