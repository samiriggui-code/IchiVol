# Skill — Ichimoku

Procédure de lecture Ichimoku (théorie). Les chiffres viennent uniquement des outils moteur.

## Ordre de lecture
1. Prix vs kumo (au-dessus / dedans / en-dessous).
2. Tenkan vs Kijun (croisement, pente).
3. Chikou vs prix et vs kumo (confirmation retardée).
4. Épaisseur / twist du nuage comme zone de friction.

## Interdits
- Ne pas inventer Tenkan/Kijun/Senkou.
- Ne pas voter LONG/SHORT : expliquer le verdict moteur.
